# OpenBSD Device Support Database

This is a searchable database of devices supported by OpenBSD.

## Why

Easy way to find out if a device is supported. Just input the device name. No looking through mailing list archives or Reddit threads.

## Tech stack

NextJS, TypeScript, TailwindCSS, Prisma ORM

## Deployment

Currectly deployed on Vercel with Supabase as the PostgreSQL host.

[Live Site](https://obsd-device-support.vercel.app/)
